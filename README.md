# HursaFlow — Third-Party Sources

This repository provides third-party open-source source materials, license notices, and build documentation associated with HursaFlow, a local-first Windows desktop application.

## Available Source Materials

### FFmpeg n9.0.2

**[View FFmpeg n9.0.2 Source Code and Licenses](https://github.com/HursaFlow/HursaFlow-ThirdParty-Sources/releases/tag/ffmpeg-n9.0.2)**

This release provides:

- FFmpeg n9.0.2 source archive.
- FFmpeg license materials.
- Build instructions.
- MSYS2 source archives for GCC runtime libraries, winpthreads, zlib, bzip2, and libiconv.
- Documentation describing the included runtime dependencies.

See the release assets for the available downloads.

## Licensing

Third-party components remain subject to their respective licenses.

The materials in this repository are provided to support source availability, license attribution, and transparency. Their publication does not by itself establish full license compliance for any particular HursaFlow distribution.

## Scope

This repository contains third-party source and licensing materials. It is not the HursaFlow application source-code repository.
